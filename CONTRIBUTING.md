# Guía para Contribuir a MentorAI

¡Gracias por tu interés en contribuir a MentorAI! Tu ayuda es muy valiosa para mejorar este proyecto.

## Cómo Contribuir

Hay varias formas en las que puedes contribuir a MentorAI:

1.  **Reportar Errores:** Si encuentras un error, por favor abre un `Issue` en GitHub con una descripción clara del problema, los pasos para reproducirlo y la versión de la aplicación y sistema operativo que estás utilizando.

2.  **Sugerir Mejoras:** ¿Tienes una idea para una nueva característica o una mejora en la experiencia de usuario? Abre un `Issue` para discutirla.

3.  **Contribuir Código:**
    *   Haz un `fork` del repositorio.
    *   Crea una nueva rama (`git checkout -b feature/tu-caracteristica` o `bugfix/tu-arreglo`).
    *   Realiza tus cambios y asegúrate de que el código cumpla con los estándares de estilo del proyecto.
    *   Escribe pruebas unitarias para tus cambios, si aplica.
    *   Asegúrate de que todas las pruebas existentes pasen.
    *   Haz un `commit` de tus cambios con un mensaje claro y descriptivo.
    *   Haz un `push` a tu rama (`git push origin feature/tu-caracteristica`).
    *   Abre un `Pull Request` al repositorio principal, describiendo tus cambios y por qué son necesarios.

4.  **Mejorar la Base de Conocimiento:** La base de conocimiento es el corazón de MentorAI. Puedes contribuir añadiendo nuevas explicaciones, comandos, tutoriales o consejos de seguridad. Los archivos de conocimiento se encuentran en la carpeta `knowledge_base` y están en formato JSON.

5.  **Mejorar la Documentación:** Ayuda a que la documentación sea más clara, precisa y completa.

## Estándares de Código

*   **Python:** Sigue las directrices de estilo PEP 8.
*   **JavaScript/React Native:** Sigue las convenciones de estilo de Airbnb o Prettier.
*   **Comentarios:** Comenta tu código cuando sea necesario para explicar la lógica compleja.
*   **Nombres de Variables:** Utiliza nombres descriptivos para variables y funciones.

## Proceso de Pull Request

1.  Abre un `Pull Request` desde tu `fork` a la rama `main` del repositorio original.
2.  Asegúrate de que tu `Pull Request` tenga un título descriptivo y una descripción detallada de los cambios.
3.  Un mantenedor del proyecto revisará tu `Pull Request` y podrá solicitar cambios o aclaraciones.
4.  Una vez aprobado, tus cambios serán fusionados.

¡Esperamos tus contribuciones para hacer de MentorAI una herramienta aún mejor!
