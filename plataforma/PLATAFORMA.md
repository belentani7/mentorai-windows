# Diseño de plataforma — MentorAI

## Modelo

tutor local de informática (CLI + escritorio), para personas que aprenden Windows, CMD, Python o Git desde cero, sin conexión fiable.

## Principio de diseño

muro cero para el alumno: el conocimiento no se bloquea.
