# Estrategia de Branding y Press Kit para el Asistente Educativo IA

## 1. Nombre del Producto
**MentorAI** (Mentor de Inteligencia Asistida)

## 2. Slogan
"Tu guía inteligente para el mundo digital: Aprende, Protege, Domina."

## 3. Identidad Visual

### 3.1. Logo (Concepto)
Un icono que combine un cerebro estilizado (representando inteligencia y aprendizaje) con un escudo (simbolizando seguridad y protección). Los colores primarios serían tonos de azul (confianza, tecnología) y verde (crecimiento, seguridad).

### 3.2. Paleta de Colores
*   **Azul Principal:** #007AFF (Confianza, Innovación)
*   **Verde Secundario:** #34C759 (Seguridad, Crecimiento)
*   **Gris Neutro:** #8E8E93 (Profesionalismo, Claridad)
*   **Blanco/Negro:** Para texto y fondos, asegurando contraste y accesibilidad.

### 3.3. Tipografía
*   **Encabezados:** Montserrat (moderna, legible)
*   **Cuerpo de Texto:** Open Sans (clara, accesible)
*   **Código/Terminal:** JetBrains Mono (monospaced, optimizada para código)

## 4. Mensajes Clave para el Press Kit

### 4.1. Título del Comunicado de Prensa
"Presentamos MentorAI: El Asistente Educativo Multiplataforma que Revoluciona el Aprendizaje Digital con Privacidad y Seguridad."

### 4.2. Resumen Ejecutivo
MentorAI es una innovadora aplicación multiplataforma (Windows 11 y Android) diseñada para empoderar a usuarios de todos los niveles en el dominio de la informática básica, la programación y la seguridad digital. A diferencia de las IAs generativas, MentorAI actúa como un "profesor" interactivo, guiando al usuario paso a paso a través de comandos de terminal, paneles de control y conceptos de seguridad en criptomonedas, todo ello con un enfoque inquebrantable en la privacidad y el procesamiento local de datos.

### 4.3. Características Destacadas
*   **Aprendizaje Interactivo:** Guía contextual en tiempo real sobre lo que el usuario ve en pantalla.
*   **Privacidad por Diseño:** Procesamiento 100% local de la información, sin envío de datos sensibles a la nube.
*   **Seguridad Avanzada:** Filtrado automático de datos sensibles y cifrado local para proteger la información del usuario.
*   **Multiplataforma:** Disponible para Windows 11 y Android, cubriendo un amplio espectro de dispositivos.
*   **Contenido Educativo Integral:** Desde CMD y Python hasta la seguridad en Binance y Trust Wallet.
*   **Accesibilidad Primero:** Diseñado para ser usable por todos, incluyendo personas con discapacidades visuales.

### 4.4. Citas (Ejemplo)
"Creemos firmemente que el conocimiento y la seguridad digital deben ser accesibles para todos. Con MentorAI, hemos creado una herramienta que no solo enseña, sino que también protege, permitiendo a los usuarios explorar el mundo digital con confianza y autonomía." - [Nombre del Fundador/CEO]

## 5. Instrucciones de Lanzamiento (Borrador)
1.  **Preparación del Repositorio GitHub:** Asegurar que todo el código fuente esté limpio, documentado y listo para ser público.
2.  **Licenciamiento:** Confirmar la licencia de código abierto (ej. MIT) para el proyecto.
3.  **Compilación y Empaquetado:** Generar los instaladores finales para Windows (.exe/.msi) y Android (.apk/.aab).
4.  **Sitio Web del Producto:** Crear una landing page sencilla con información clave, enlaces de descarga y el press kit.
5.  **Comunicado de Prensa:** Distribuir a medios tecnológicos y blogs especializados.
6.  **Publicación en GitHub:** Lanzar el repositorio público.
7.  **Anuncio en Foros y Comunidades:** Compartir en comunidades relevantes de programación, seguridad y tecnología.
