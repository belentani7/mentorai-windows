MentorAI para Windows

Profesor local de informática para Windows 10/11: CMD, PowerShell, Python, Git, Docker, Android y seguridad digital. Explica, no ejecuta; tus datos nunca salen de tu equipo.

Documentación Repositorio

Características

Una aplicación de escritorio PyQt5 con una base de conocimiento local de 36 temas: explicaciones con pasos, consejos de seguridad y progreso guardado solo en tu equipo.

🖥️ App de escritorio real

Interfaz PyQt5 para Windows 10/11 con navegación por temas, historial cifrado, progreso local y Professor Mode (lectura explícita por el usuario, nunca automática).

📴 100% sin conexión

El motor y la base de conocimiento JSON funcionan offline. No hay telemetría, ni cuentas, ni dependencias de red en el núcleo.

🔐 Datos cifrados

Consultas e historial cifrados con AES-256-GCM; en Windows la clave maestra se protege con DPAPI y el borrado de datos es explícito.

⚡ Hero ligero

Esta página no usa frameworks JavaScript: un shader WebGL propio (FBM con parallax, pausado fuera de pantalla) y degradado CSS como respaldo.

Stack Tecnológico

Tecnologías reales del repositorio.

  • Python 3.12
  • PyQt5
  • SQLite
  • AES-256-GCM
  • Windows DPAPI
  • PyInstaller
  • pytest
  • GitHub Actions
  • WebGL (GLSL)
